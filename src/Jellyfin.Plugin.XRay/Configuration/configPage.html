X-Ray

Recognizes cast members in your videos so you can see who is in the current scene while watching (pause, show the player controls, or press X). Scene data is built by the Build X-Ray scene data scheduled task, or on demand from the player. The first analysis downloads the ONNX runtime and face models (~90 MB) from NuGet.

What to analyze

Recognition

Lower is more precise but slower.
Higher means fewer false matches but more missed faces. 0.35 - 0.5 works well.
Bridges cut-aways and over-the-shoulder shots within a scene.

Web client

Edits jellyfin-web's index.html. If the server cannot write it, load /XRay/ClientScript with a script injector plugin instead.
